# 线程池工作线程生命周期图

## Worker线程概述

线程池中的工作线程由Worker类封装，每个Worker持有一个Thread实例和一个首次任务。

```mermaid
flowchart TD
    subgraph WorkerCreation["Worker创建"]
        A["addWorker()"] --> B["new Worker(firstTask)"]
        B --> C["创建Thread<br/>thread = factory.newThread(this)"]
        C --> D["启动线程<br/>thread.start()"]
    end
    
    subgraph WorkerRun["Worker运行"]
        D --> E["runWorker(this)"]
        E --> F["执行firstTask或获取任务"]
        F --> G["beforeExecute()"]
        G --> H["task.run()"]
        H --> I["afterExecute()"]
        I --> J{"获取下一个任务"}
        J -->|"成功"| G
        J -->|"失败"| K["processWorkerExit()"]
    end
    
    subgraph WorkerExit["Worker退出"]
        K --> L["从workers集合移除"]
        L --> M["递减ctl中的线程计数"]
        M --> N["尝试终止线程池"]
    end
    
    style A fill:#e3f2fd
    style D fill:#c8e6c9
    style H fill:#bbdefb
    style K fill:#ffcdd2
```

## getTask()获取任务流程

```mermaid
flowchart TD
    A["getTask()"] --> B{"线程池状态 >= SHUTDOWN<br/>且(状态 >= STOP 或 队列为空)?"}
    
    B -->|"是"| C["返回null<br/>线程退出"]
    B -->|"否"| D{"当前线程数 > maximumPoolSize<br/>或(空闲超时且线程数 > corePoolSize)?"}
    
    D -->|"是"| E{"CAS递减线程数成功?"}
    E -->|"成功"| C
    E -->|"失败"| A
    
    D -->|"否"| F["从队列获取任务<br/>workQueue.poll(timeout)"]
    F --> G{"获取成功?"}
    G -->|"成功"| H["返回任务"]
    G -->|"失败"| A
    
    style A fill:#e3f2fd
    style C fill:#ffcdd2
    style H fill:#c8e6c9
```

## 工作线程生命周期说明

| 阶段 | 操作 | 说明 |
|------|------|------|
| 创建 | addWorker() | 创建Worker对象并启动线程 |
| 初始化 | new Worker(firstTask) | 设置首次任务，创建线程 |
| 运行 | runWorker() | 循环获取并执行任务 |
| 获取任务 | getTask() | 从队列获取任务，可能阻塞 |
| 执行任务 | task.run() | 执行任务的run方法 |
| 退出 | processWorkerExit() | 清理Worker，更新线程计数 |

## 线程回收机制

```mermaid
flowchart TD
    A["工作线程空闲"] --> B{"allowCoreThreadTimeOut?"}
    
    B -->|"是"| C["所有线程空闲超时都可回收"]
    B -->|"否"| D{"当前线程数 > corePoolSize?"}
    
    D -->|"是"| E["空闲超过keepAliveTime后回收"]
    D -->|"否"| F["核心线程不回收<br/>继续等待任务"]
    
    C --> G["线程退出"]
    E --> G
    F --> A
    
    style G fill:#ffcdd2
    style F fill:#c8e6c9
```

## 关键概念

- **Worker**：线程池的工作线程封装类，实现了Runnable接口
- **firstTask**：Worker创建时的首个任务，可能为null
- **runWorker()**：Worker的主循环方法，不断获取并执行任务
- **getTask()**：从工作队列获取任务，支持超时等待
- **线程回收**：空闲线程超时后自动退出，减少资源占用
