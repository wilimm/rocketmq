# 线程池状态与任务处理关系图

## 不同状态下的任务处理方式

线程池在不同状态下对任务的处理方式不同。

```mermaid
flowchart TD
    subgraph TaskHandling["任务处理决策"]
        A["提交任务"] --> B{"检查线程池状态"}
        
        B -->|"RUNNING"| C{"线程数 < corePoolSize?"}
        C -->|"是"| D["创建核心线程执行"]
        C -->|"否"| E["任务入队"]
        E --> F["等待空闲线程"]
        
        B -->|"SHUTDOWN"| G["拒绝任务<br/>抛出RejectedExecutionException"]
        B -->|"STOP"| G
        B -->|"TIDYING"| G
        B -->|"TERMINATED"| G
    end
    
    style A fill:#e3f2fd
    style B fill:#e1bee7
    style D fill:#c8e6c9
    style E fill:#bbdefb
    style G fill:#ffcdd2
```

## 状态检查流程

```mermaid
flowchart TD
    A["任务处理前检查"] --> B{"runState >= SHUTDOWN?"}
    
    B -->|"否(RUNNING)"| C["正常处理任务"]
    B -->|"是"| D{"runState >= STOP?"}
    
    D -->|"否(SHUTDOWN)"| E{"任务是否为null<br/>且队列为空?"}
    E -->|"是"| F["返回null<br/>线程退出"]
    E -->|"否"| G["继续处理队列任务"]
    
    D -->|"是(STOP/TIDYING/TERMINATED)"| F
    
    style A fill:#e3f2fd
    style C fill:#c8e6c9
    style F fill:#ffcdd2
    style G fill:#bbdefb
```

## 线程池生命周期全景图

```mermaid
flowchart TD
    subgraph Lifecycle["线程池生命周期"]
        direction LR
        
        subgraph Running["RUNNING阶段"]
            R1["接受新任务"]
            R2["创建工作线程"]
            R3["处理队列任务"]
        end
        
        subgraph Shutdown["SHUTDOWN阶段"]
            S1["拒绝新任务"]
            S2["等待队列清空"]
            S3["回收空闲线程"]
        end
        
        subgraph Stop["STOP阶段"]
            T1["拒绝新任务"]
            T2["清空队列"]
            T3["中断所有线程"]
        end
        
        subgraph Terminated["终止阶段"]
            E1["TIDYING: 执行terminated()"]
            E2["TERMINATED: 完全终止"]
        end
    end
    
    Running -->|"shutdown()"| Shutdown
    Running -->|"shutdownNow()"| Stop
    Shutdown -->|"队列空+线程数0"| Terminated
    Stop -->|"线程数0"| Terminated
    
    style R1 fill:#c8e6c9
    style S1 fill:#fff9c4
    style T1 fill:#ffcdd2
    style E2 fill:#e1bee7
```

## 状态与任务处理关系说明

| 状态 | 接受新任务 | 处理队列任务 | 中断执行任务 | 典型场景 |
|------|----------|-------------|-------------|---------|
| RUNNING | ✅ 是 | ✅ 是 | ❌ 否 | 正常运行 |
| SHUTDOWN | ❌ 否 | ✅ 是 | ❌ 否 | 优雅关闭 |
| STOP | ❌ 否 | ❌ 否 | ✅ 是 | 立即关闭 |
| TIDYING | ❌ 否 | ❌ 否 | ❌ 否 | 即将终止 |
| TERMINATED | ❌ 否 | ❌ 否 | ❌ 否 | 已终止 |

## 关键概念

- **状态优先检查**：任何操作前先检查线程池状态
- **状态决定行为**：不同状态下对任务的处理方式完全不同
- **状态转换不可逆**：一旦进入关闭流程，无法恢复运行
- **优雅关闭**：SHUTDOWN状态保证队列任务执行完成
