# 字段说明示例

## 基本格式

当文档中出现结构体字段说明时，需按以下表格格式展开：

| 列名 | 说明 | 必填 |
|------|------|------|
| 字段 | 字段名称 | ✅ |
| 示例值 | 字段对应的典型值或默认值 | ✅ |
| 说明 | 字段的含义描述 | ✅ |

## 示例：Linux task_struct 结构体字段

| 字段 | 示例值 | 说明 |
|------|--------|------|
| `state` | `TASK_RUNNING (0)` | 线程状态，见下方状态详解 |
| `pid` | `12345` | 进程/线程的唯一标识符，每个线程有独立pid |
| `tgid` | `12345` | 线程组ID，同一线程组的线程共享，等于主线程pid |
| `mm` | `0xffff...` | 内存描述符指针，指向进程的虚拟内存空间 |
| `files` | `0xffff...` | 打开文件表指针，指向文件描述符表 |

## 示例值类型

| 类型 | 格式 | 示例 |
|------|------|------|
| 数值 | 直接写数值 | `12345`、`0`、`-1` |
| 枚举 | 枚举名(值) | `TASK_RUNNING (0)` |
| 指针/地址 | 简化表示 | `0xffff...`、`NULL` |
| 字符串 | 带引号 | `"localhost"`、`"/tmp"` |
| 布尔 | true/false | `true`、`false` |
