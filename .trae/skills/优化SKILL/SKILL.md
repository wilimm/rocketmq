# 优化SKILL

## 描述

优化技能文件 SKILL.md 的格式和内容，确保符合官方规范，同时保留核心参考内容。

## 使用场景

- 需要优化技能文件格式
- 需要规范化技能结构
- 需要精简冗余内容

## 指令

### 官方规范格式

SKILL.md 必须遵循以下格式：

```markdown
---
name: "技能名称"
description: "简要描述功能(1)和触发条件(2)，不超过200字符"
---

# 技能名称

## 描述
详细说明技能的作用和定位。

## 使用场景
- 场景1
- 场景2

## 指令
具体的操作步骤和规范。

## 示例 (可选)
示例文件引用或代码示例。
```

### 必需字段

| 字段 | 位置 | 说明 |
|------|------|------|
| `name` | frontmatter | 技能唯一标识符 |
| `description` | frontmatter | **关键**：必须包含(1)功能说明和(2)触发条件，不超过200字符 |
| 详细内容 | body | 描述、使用场景、指令、示例 |

### 文件夹结构

```
skill-name/
├── SKILL.md               # 必须：智能体的核心指令
├── examples/              # 可选：输入/输出示例
├── templates/             # 可选：可复用的模板
└── resources/             # 可选：参考文件、运行脚本或素材
```

### 文件夹类型说明

| 文件夹 | 用途 | 内容特点 |
|--------|------|---------|
| `examples/` | 示例文件 | 演示性内容，展示"怎么做" |
| `templates/` | 模板文件 | 可复用的文档模板 |
| `resources/` | 资源文件 | 参考性数据，提供"查什么" |

### 精简原则

**可以精简**：
- 重复描述
- 冗余修饰词
- 过度的格式说明
- 可提取到 examples/ 的详细示例
- 可提取到 resources/ 的参考数据

**不能精简**：
- 知识体系表格
- 核心参考内容
- 关键约束和注意事项
- 工作流程说明
- 模板引用

### 优化步骤

1. **检查格式**：确保包含描述、使用场景、指令、示例四个标准章节
2. **精简内容**：删除冗余描述，保留核心指令
3. **分离资源**：将详细示例移到 examples/，参考数据移到 resources/
4. **验证完整性**：确保核心参考内容完整保留

## 示例

### 优化前

```markdown
# 技能名称

你是一个专业的XXX专家，负责XXX工作。

## 1. 分析阶段
- 检查XXX
- 评估XXX

## 2. 执行阶段
...
```

### 优化后

```markdown
---
name: "技能名称"
description: "功能说明。触发条件说明。"
---

# 技能名称

## 描述

功能说明。

## 使用场景

- 场景1
- 场景2

## 指令

### 工作流程

1. **分析阶段**：检查XXX、评估XXX
2. **执行阶段**：...

## 示例

参见 [examples/示例文件.md](examples/示例文件.md)
```
