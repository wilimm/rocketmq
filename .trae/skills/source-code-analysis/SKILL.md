# 源码解读技能

## 执行步骤

```mermaid
flowchart LR
    A[1.入口定位] --> B[2.结构梳理]
    B --> C[3.概念提取]
    C --> D[4.关系分析]
    D --> E[5.流程追踪]
    E --> F[6.源码核对]
    F --> G[7.文档生成]
```

### 步骤1：入口定位

**目标**：找到代码的主入口和核心模块。

| 入口类型 | 识别标志与搜索方法 |
|----------|-------------------|
| 主入口类 | `main` 方法 → 搜索 `public static void main` |
| 核心模块 | `pom.xml` 依赖 → 查看模块结构和依赖关系 |
| 配置入口 | `@Configuration`、`application.yml` → 搜索配置类和属性文件 |
| API 入口 | `@RestController`、`@RequestMapping` → 搜索 Controller |

### 步骤2：结构梳理

**目标**：理清代码的组织结构和层次关系。

| 分析维度 | 方法与输出 |
|----------|-----------|
| 目录/包结构 | 查看目录层级 → 模块划分图 |
| 类层次 | 分析继承关系 → 类继承图 |
| 依赖关系 | 分析 import 和引用 → 依赖关系图 |

### 步骤3：概念提取

**目标**：识别核心概念和领域实体。

| 概念类型 | 识别标志 | 处理方式 |
|----------|----------|----------|
| 领域实体 | `@Entity`、数据类 | 记录字段、类型、含义 |
| 核心接口 | `interface` 定义 | 记录方法签名、职责 |
| 枚举类型 | `enum` 关键字 | 记录所有枚举值及含义 |
| 常量定义 | `static final` | 记录常量名、值、用途 |
| 配置项 | `@ConfigurationProperties` | 记录配置名、默认值、说明 |

### 步骤4：关系分析

**目标**：理解概念之间的关联。

| 关系类型 | 分析方法与输出 |
|----------|---------------|
| 调用关系 | 方法调用链 → 调用链图 |
| 依赖关系 | import 分析 → 依赖图 |
| 继承关系 | extends 分析 → 继承树 |
| 组合关系 | 字段类型分析 → 组合结构图 |

### 步骤5：流程追踪

**目标**：跟踪核心业务流程。

| 流程类型 | 入口点与分析方法 |
|----------|-----------------|
| 请求流程 | Controller → 跟踪请求处理链路 |
| 数据流程 | 数据入口 → 跟踪数据流转路径 |
| 事件流程 | 事件发布点 → 跟踪事件监听链 |
| 定时流程 | `@Scheduled` → 跟踪定时任务逻辑 |

### 步骤6：源码核对（必做）

**核心原则：所有概念定义必须与源码内容保持一致，禁止凭记忆或推测编写。**

| 核对维度 | 核对方法 |
|----------|----------|
| 类名/方法名/方法签名 | 确认准确拼写、参数类型、返回值、异常 |
| 字段类型 | 确认字段声明和泛型类型 |
| 注解/常量/枚举 | 确认注解属性值、常量值、枚举值和顺序 |
| 配置项默认值 | 确认字段初始化值或 `@Value` 注解默认值 |

**常见错误**：枚举写成String、布尔写成int、泛型遗漏、默认值/单位错误、数值缺少单位。

### 步骤7：文档生成

**目标**：生成结构清晰、内容准确的技术文档。

#### 7.1 文档结构模板

```markdown
# [主题名称]

> 文档说明：简述文档目的和适用场景

## 一、概述
[主题简介，说明是什么、解决什么问题]

## 二、核心概念
### 2.1 [核心类/接口名称]
[类/接口说明]
**源码位置**：[ClassName.java](file:///path/to/ClassName.java)
**核心字段/方法**：| 名称 | 类型 | 说明 |

## 三、核心流程
### 3.1 [流程名称]
[流程说明 + mermaid流程图]

## 四、配置说明
| 配置项 | 默认值 | 说明 |

## 五、使用示例
[代码示例]

## 六、参考资料
- [相关文档链接]
```

#### 7.2 源码链接与完整性标准

**链接格式**：`类名 ([ClassName.java](file:///path/to/ClassName.java))`

**完整性要求**：数据类需包含所有字段、枚举类需包含所有枚举值、配置类需包含所有配置项及默认值、接口类需包含所有方法签名。

---

## 注意事项

- 所有信息必须来自源码，禁止凭记忆或推测，每个概念标注源码位置
- 文档开头说明源码版本，使用图表增强可读性（流程图、类图、时序图等）
