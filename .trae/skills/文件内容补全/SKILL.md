# 文件内容补全

## 内容补全规则

1. 检查当前文件的内容是否完整匹配源码中本章节聚焦的所有内容，如果不完整则依据源码进行补充
2. 数值一定要带上可读性高的单位，需要保留原始数据和单位
3. 概念解释优化：补充问题背景、触发时机、优化方案、简要说明，增加可读性
4. 补充图表、代码中的变量/参数的默认值，并添加简要说明，增加可读性
5. 为复杂流程添加可视化图例
6. 如果表格可读性更高用表格，如果列表可读性更高用列表，可读性优先
7. 引用内容必须添加markdown锚点，尽量使用相对路径

## 常用单位规范

| 类型 | 单位 |
|------|------|
| 时间 | ms、s、min、h |
| 大小 | B、KB、MB、GB |
| 数量 | 个、条、次 |

## 要求

1. 所有内容必须与源码一致，禁止凭记忆或推测编写
2. 统一标题、列表、代码格式
